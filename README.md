# 🛍️ Shopora — E-Commerce Demo Website

Shopora is a responsive e-commerce demo website inspired by modern online shopping platforms. It provides an interactive shopping experience with product browsing, search, filtering, cart management, wishlist functionality, and a demo checkout process.

## ✨ Features

- **Product Listing** — Browse products in a responsive product grid.
- **Product Search** — Find products using the search functionality.
- **Category Filtering** — Filter products by category.
- **Price Sorting** — Sort products by price.
- **Shopping Cart** — Add products, update quantities, remove items, and calculate the total.
- **Wishlist** — Add or remove favorite products and view your wishlist.
- **Login Modal** — Demonstration login interface.
- **Seller Registration** — Demonstration interface for seller registration.
- **Checkout Modal** — Demo checkout interface with six-digit PIN validation.
- **Responsive Design** — Designed to work across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

You can run Shopora locally without installing any additional packages.

### Option 1: Open in a Browser

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/shopora.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

Replace `YOUR-USERNAME` with your GitHub username.

### Option 2: Use VS Code

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the website using the **Live Server** extension, if installed.

## 🌐 Deployment

Shopora can be deployed as a static website using **Vercel**.

1. Push the project files to your GitHub repository.
2. Sign in to Vercel using your GitHub account.
3. Import the `shopora` repository into Vercel.
4. Configure the project as a static website if prompted.
5. Deploy the project.
6. Open the generated deployment URL to access your website online.

For a basic HTML, CSS, and JavaScript project, a build command is generally not required.

## ⚠️ Important Notes

This project is a **frontend demonstration**, not a fully functional production e-commerce platform.

- Login and seller registration are demonstration interfaces; they do not create real accounts.
- Cart and wishlist functionality operate on the frontend.
- Checkout does not process real payments or create real orders.
- No backend, database, or payment gateway is configured.
- Do not enter real passwords, payment details, or other sensitive information.
